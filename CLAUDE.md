# home-ops

Ansible deploys self-hosted Services as Docker containers onto Hosts. Terraform (state in Terraform Cloud) owns DNS, the tailnet policy and its own workspaces. Renovate bumps pinned versions, and merged Version Bumps Auto-deploy through Semaphore.

- **Terms**: [CONTEXT.md](CONTEXT.md) is the glossary. Use its words (Host, Service, Assignment, Step, Deploy, Version Bump, Auto-deploy) in code, docs and commit messages.
- **Current state**: `docs/`, starting at [docs/README.md](docs/README.md). `.specs/` is design history; where it disagrees with the code or `docs/`, the code and `docs/` win.
- **Commands**: `just --list`. mise (`.mise/config.toml`) pins the tools, sets the Ansible env and loads `.env`.
- **Without mise**: CI and Semaphore run with only `ANSIBLE_CONFIG=ansible/ansible.cfg`, so new Ansible paths must resolve relative to that file or the playbook. mise also sets `ANSIBLE_PLAYBOOK_DIR`, which changes where relative `include_vars` paths resolve; prefix commands copied from CI with `env -u ANSIBLE_PLAYBOOK_DIR`.

## Safety

- **Real runs need a same-turn ask.** Run a real Deploy, `terraform apply` or `just tf::apply` only when the user asks for that run in the current turn. Otherwise verify with `--check --diff`, `--syntax-check`, `just docs` and `terraform validate`.
- **Secrets**: all live in Bitwarden Secrets Manager. Reference them as `bws_secrets.<KEY>` and set `no_log: true` on any Service that does.
- **Token files**: `.env` holds access tokens. Leave it unread.

## Docs upkeep

- **Generated pages** (header `GENERATED by just docs`) change only through their sources plus `just docs`.
- **Covered docs**: hand-written docs, this file and the skills list the code they describe in `covers:` frontmatter. A commit that changes covered code also stages every doc covering it, or carries the trailer `Docs: none (<reason>)`. When the `docs-covers` hook fails, or before committing covered code, use the update-docs skill.
- **No versions**: docs never name versions. Renovate owns them, and its commits skip local hooks.

## Conventions

- **Commits**: Conventional Commits, with the scopes in `git log` (`feat(ansible)`, `feat(terraform)`, `ci`, `chore(mise)`, `docs`).
- **Service files**: the file name is the top-level key, and every Service has a `description:`.
- **Comments**: they carry the why (setup steps, gotchas, upstream links), as in the existing files. A known limit gets `shortcut: <the limit>, <when to upgrade>`; older ones say `ponytail:`.
